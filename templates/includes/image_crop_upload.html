{% comment %} Shared "crop before upload" progressive enhancement. Usage: render a normal and add the class `crop-upload`, plus optional data attributes: - data-crop-ratio: width:height of the crop frame, either "W:H" or a plain decimal (width/height). Defaults to "1" (square). - data-crop-output: the longer side of the exported image in pixels. Defaults to 800. On file selection this script opens a modal where the picked image can be panned and zoomed inside a fixed-ratio frame. "Apply Crop" rasterizes the selection to a canvas at the configured output size and replaces the input's file with that cropped JPEG, so every upload through this widget ends up the same dimensions regardless of what the original photo looked like. If the browser lacks FileReader/canvas/DataTransfer support, or this script fails to load, the input is left completely alone and behaves like a plain file upload — cropping is an enhancement, never a hard requirement to submit the form. {% endcomment %}
