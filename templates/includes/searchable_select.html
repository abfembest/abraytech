{% comment %} Shared "searchable select" progressive enhancement. Usage: render a completely normal {% for dept in departments %} {% endfor %} On DOMContentLoaded this script finds every `select.searchable-select` and wraps it with a search-as-you-type dropdown, while leaving the original remains fully visible and usable, so form submission can never silently fail the way the old ` + ` pattern did (a option's `value` attribute is what browsers write into the input on selection, not its label — mismatches there were exactly what caused "This field is required" errors on already-filled-in fields). If content containing new .searchable-select elements is injected after page load (e.g. into a modal), call window.enhanceSearchableSelects(root) with the new root element to enhance just that subtree. {% endcomment %}
